# Contributing
Contributions via bug reports, bug fixes, are welcome. If you have ideas about features to be implemented, please open an issue so we can discuss the best way to implement it.

## How to build?
Clone the repository, install the dependencies with `pnpm`, and build with `pnpm run dev`. It automatically moves the files into `docs/test-vault` and hot reloads the plugin.

    $ git clone ssh://git@192.168.0.150:2424/ks/NotePalace.git
    $ cd NotePalace
    ~/NotePalace$ pnpm install
    ~/NotePalace$ pnpm run dev
